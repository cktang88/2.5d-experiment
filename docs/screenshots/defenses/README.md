# Defense browser validation

Run `python tests/defense_validation.py` with the Vite server on port 5173. The script saves raw browser JPEGs and its check results here. It stops the animation loop for repeatable stepping, creates a flat supported platform, grants resources, and constructs a lineup of defenses. Combat checks spawn stationary brutes in this test area. The picker and range captures show the in-game interface; the lineup is a controlled fixture, not a natural gameplay scene. The screenshots have not been edited after capture.
