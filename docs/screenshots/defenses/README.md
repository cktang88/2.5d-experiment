# Defense browser validation

These captures were made by the former `tests/defense_validation.py` browser script. Its checks now live in `tests/e2e/defenses.js` (run `npm run e2e -- defenses` with the Vite server on port 5173), which does not save screenshots. It stops the animation loop for repeatable stepping, creates a flat supported platform, grants resources, and constructs a lineup of defenses. Combat checks spawn stationary brutes in this test area. The picker and range captures show the in-game interface; the lineup is a controlled fixture, not a natural gameplay scene. The screenshots have not been edited after capture.
